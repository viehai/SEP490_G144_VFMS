# Invoice font

`NotoSans-Regular.ttf` is the unmodified Noto Sans regular TrueType font from the
official Noto fonts repository, distributed under SIL Open Font License 1.1.
The accompanying `OFL.txt` is the upstream license.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

SHA-256: `B85C38ECEA8A7CFB39C24E395A4007474FA5A4FC864F6EE33309EB4948D232D5`

One embedded font supplies portable Vietnamese Unicode glyphs without depending
on fonts installed on the server. PDFsharp embeds only the used glyph subset in
each generated PDF. The font is a required application resource, not generated
invoice storage.
